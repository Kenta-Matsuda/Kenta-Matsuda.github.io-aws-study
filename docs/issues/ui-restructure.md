# Issue: UI構造の全面リファクタリング

## 概要

ヘッダーが「Exam」「Language」「Theme」「API Key」と各要素が並列に並んでおり、煩雑で洗練されていない。
設定系を1つのボタン（アイコンのみ）に集約し、試験選択をカテゴリ別サイドバーに移動することで、
シンプルで分かりやすく洗練されたUIに再設計する。

## 変更内容

### 1. ヘッダーの簡素化
- **Before**: Exam / Language / Theme / API Key の4ボタンが横並び
- **After**: サイトタイトル + 設定アイコン（歯車）のみ
  - 設定ボタンはテキストラベル不要、アイコンのみ
  - 試験名はサイドバーで選択中のものがヘッダーサブタイトルに表示される

### 2. 統合設定モーダル
1つの設定画面で以下を管理:
- 言語切り替え (日本語 / English)
- テーマ切り替え (Light / Dark / System)
- AIプロバイダ選択 & APIキー登録 (Gemini / OpenAI)

### 3. 試験選択サイドバー
- 試験レベル別にグループ化:
  - **Foundational**: CLF-C02, AIF-C01
  - **Associate**: SAA-C03, DVA-C02, SOA-C03, MLA-C01, DEA-C01, AIP-C01
  - **Professional**: SAP-C02, DOP-C02
  - **Specialty**: ANS-C01, SCS-C03
  - **Business**: AIB-C01
- モバイルではハンバーガーメニューで開閉
- デスクトップでは左サイドバーとして常時表示（折り畳み可）

### 4. URLルーティング
- 試験変更時にURLのハッシュが変わる
  - 例: `https://kenta-matsuda.github.io/Kenta-Matsuda.github.io-aws-study/#clf`
  - 例: `https://kenta-matsuda.github.io/Kenta-Matsuda.github.io-aws-study/#saa`
- ページ読み込み時にハッシュから試験を復元
- 短縮コード対応: `clf` → `clf-c02`, `saa` → `saa-c03` など

### 5. 学習ロードマップの分離
- 試験固有のステップ（申し込み手順等）はそのまま試験別に表示
- 共通コンテンツ（AWS学習の基礎的リソース等）を抽出し、
  全試験共通の「共通学習リソース」セクションとして独立表示

## 技術的な実装方針
- ルーティング: `location.hash` を利用したクライアントサイドルーティング
- サイドバー: 既存の左サイドバー（ドメインチャート）の上に試験セレクタを配置
- 設定モーダル: 既存のsettingsModalを拡張し、言語・テーマ設定を統合
- i18n: 新規キーを `sidebar.*`, `settings.language`, `settings.theme` 等に追加

## 受入条件
- [ ] ヘッダーにはサイトタイトルと設定アイコンのみ表示される
- [ ] 設定アイコンクリックで言語・テーマ・APIキーの統合設定画面が開く
- [ ] 試験選択がカテゴリ別にグループ化されたサイドバーから行える
- [ ] 試験変更時にURL（ハッシュ）が変わる
- [ ] URLのハッシュから直接試験ページにアクセスできる
- [ ] 学習ロードマップの共通部分が分離・集約されている
- [ ] モバイル表示で破綻しない
- [ ] 既存機能（クイズ、XP、チャット等）に影響がない
