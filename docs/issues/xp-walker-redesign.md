# Issue: 学習ダッシュボードのXPウォーカー刷新 (#102)

## 概要

学習ダッシュボードのXPバー上を進捗に合わせて移動する人型アイコンが、素の絵文字（🚶）をそのまま表示しており「ださい」というフィードバックが寄せられた（Issue #102）。
新規の依存や外部画像を追加せず、インラインSVGでアプリのテーマ（AWSネイビー `#232f3e` / オレンジ系アクセント）に合わせた、より凝った探検家風のキャラクターへ刷新する。

## 変更内容

### 1. マーカーの刷新（絵文字 → インラインSVG）
- **Before**: `<div id="xpWalker" class="xp-walker" ...>🚶</div>`（環境依存でレンダリングが安定しない素の絵文字）
- **After**: 同じ `#xpWalker` 内にインラインSVGの探検家キャラクター（頭・つば付き帽子・オレンジのチュニック・ネイビーのバックパック・脚と腕）を配置
  - 塗り色はXPバーのグラデーション（`#fbbf24 → #f59e0b → #ea580c`）とテーマのネイビー `#232f3e` に統一
  - `drop-shadow` で軽い立体感を付与

### 2. アニメーションのリファイン
- 全身がやさしく上下する `xpWalkBob`（微小な傾きも付与）
- 脚（前後）と腕が交互にスイングする `xpWalkLegFront` / `xpWalkLegBack` / `xpWalkArm`
- 足元の影が歩調に合わせて伸縮する `xpWalkShadow`
- 旧 `steps(1, end)` の左右反転パターンを廃止し、なめらかな `ease-in-out` の歩行モーションへ

### 3. ダークモード対応
- ダークトラック上でも視認できるよう、`html.dark` でバックパックと輪郭線をより濃いネイビー（`#10151d`）に、ドロップシャドウを強めに調整

## 技術的な実装方針
- 追加依存・外部画像なし。`index.html` に埋め込みのインラインSVG + 埋め込みCSSのみで完結
- 進捗追従の契約は**変更しない**: `js/ui.js` は従来どおり `els.xpWalker.style.left`（パーセント）で位置を設定する。SVGの歩行アニメーションは子要素（`.xp-walker__body` など）の `transform` に閉じているため、外側 `.xp-walker` の `translateX(-50%)` による位置決めと競合しない
- `aria-hidden="true"` を維持（装飾要素のためスクリーンリーダーから隠す）
- `@media (prefers-reduced-motion: reduce)` で全アニメーションを無効化するガードを維持・拡張

## 考慮したトレードオフ
- **SVGスプライトや外部画像アセット**も検討したが、静的PWA・ビルドステップ無しという方針とネットワーク制約に反するため、埋め込みインラインSVGを選択
- **JSでのSVG差し込み**ではなく静的マークアップに直接記述することで、既存の位置決めロジック（`style.left`）に一切手を入れず、リグレッションリスクを最小化

## 受入条件
- [x] `#xpWalker` が素の🚶絵文字を唯一のコンテンツとして描画しなくなり、デザインされたSVGマーカーを表示する
- [x] ウォーカーが進捗（`style.left` パーセント契約）に従ってXPバー上を移動する
- [x] `prefers-reduced-motion` でウォーカーのアニメーションが無効化される
- [x] ダークモードでも視認性が保たれる
